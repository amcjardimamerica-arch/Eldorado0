# Livro especial: Pesquisa externa

Os resultados do Claude no Chrome são gravados **no livro de cada oportunidade** (`pesquisa_externa` e `aprendizados`).
Este livro especial guarda só o resultado de oportunidades que **nunca tiveram livro** (em geral, ruído descartado) e,
em `entradas/`, os arquivos brutos de cada rodada, como prova. Para importar uma rodada nova:
`python scripts/importar_revisao_abertas.py <pasta com resultado_ABERTAS_*.json>`
